# 샘플 구글시트 데이터

공모전 시연·테스트용 **가짜(더미) 데이터**입니다. 실제 학생 정보가 아닙니다.
아래 CSV 파일들을 구글시트에 각각의 탭으로 가져오면, 바로 "샘플 앱"을 만들 수 있습니다.

## 구글시트로 만드는 방법 (약 5분)

1. [sheets.new](https://sheets.new) 로 빈 구글시트를 새로 만듭니다.
2. 아래 각 CSV 파일마다 **탭을 하나씩** 추가합니다. **탭 이름은 파일명과 똑같이** 하세요.
   - 탭 이름 예: `students`, `seatmap`, `schedule`, `course`, `contacts`, `external`, `external2`, `emergency`, `safeedu`, `teachercheck`, `ch room`, `exit`
3. 각 탭을 선택한 상태에서 **파일 → 가져오기 → 업로드** 로 해당 CSV를 올립니다.
   - 가져오기 위치: **"현재 시트 바꾸기"**, 구분자: **쉼표** 선택
4. 다 넣었으면 오른쪽 위 **공유 → "링크가 있는 모든 사용자" → 뷰어** 로 설정합니다.
5. 주소창에서 시트 ID를 복사합니다.
   `docs.google.com/spreadsheets/d/` **`이 부분`** `/edit`

이 시트 ID를 Vercel 환경변수 `NEXT_PUBLIC_SPREADSHEET_ID` 에 넣으면 샘플 앱이 완성됩니다.

## 샘플 로그인 정보

학생 화면 로그인 예시 (학번 / 이름):
- `20101` / `김민준`  (1호차, 방장)
- `20201` / `최유나`  (2호차, 방장)

> ⚠️ 전화번호 등은 모두 `010-0000-0000` 형태의 가짜 값입니다. 실제 개인정보를 넣지 마세요.
